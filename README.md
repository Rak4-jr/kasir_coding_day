# Aplikasi Kasir (PHP + MySQL, XAMPP)

1. Salin folder `kasir` ke `C:\xampp\htdocs\kasir`
2. XAMPP Control Panel: Start **Apache** dan **MySQL**
3. Buka http://localhost/phpmyadmin → tab **Import** → pilih `database.sql` → Go
4. Buka http://localhost/kasir  → login: **admin** / **password**
5. Jika password MySQL root Anda tidak kosong, ubah di `config/koneksi.php`
